CloudWatch is a monitoring service in AWS used to track performance, logs, and set alerts for resources.
its like CCTV + health monitor for your AWS resources


1. 📊 Metrics

👉 Data points collected over time

Examples:
CPU Utilization
ec2 status checks
instance resource usage

📝 Exam line:
Metrics are numerical data used to monitor AWS resources.



2. 🚨 Alarms

👉 Triggers when condition is met

Example:
CPU > 80% → send alert

Actions:
Send notification (SNS)
Stop/Terminate instance

📝 Exam line:
Alarms monitor metrics and take actions when thresholds are crossed.


3. 📜 Logs

👉 Stores application/system logs

Used for:
Debugging
Tracking errors

📝 Exam line:
CloudWatch Logs store and analyze log files from AWS resources.



4. 📈 Dashboards

👉 Visual display of metrics

Graphs
Charts
Multiple services in one place

📝 Exam line:
Dashboards provide a visual view of system performance.



5. 🔔 Events (EventBridge)

👉 Trigger actions based on events

Example:

EC2 stopped → run Lambda


To monitor CPU utilization of an EC2 instance and trigger an alarm when it exceeds a threshold.



difference between events and alarms:
Alarms: Triggered based on metric thresholds (e.g., CPU > 80%).
Events: Triggered based on specific actions or changes in AWS resources (e.g., EC2 instance stopped).
