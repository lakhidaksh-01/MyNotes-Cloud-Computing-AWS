Task 1: create DynamoDB table via CLI and GUI and perform CRUD operations

A fast and flexible NoSQL database service for any scale.

DynamoDB is preferred when we need high performance, automatic scaling, and simple key-based queries. MongoDB is better when we need flexible schema and complex querying.


GUI Method


Create Table
Open AWS Console
Search DynamoDB
Click Create Table
Table name: Students
Partition key: StudentID
Click Create

CLI Method

# Create Table
aws dynamodb create-table \
--table-name Students \
--attribute-definitions AttributeName=StudentID,AttributeType=N \
--key-schema AttributeName=StudentID,KeyType=HASH

# Create Item
aws dynamodb put-item 
--table-name Students 
--item '{"StudentID":{"N":"1"},"Name":{"S":"Daksh"}}'

# Read Item
aws dynamodb get-item 
--table-name Students 
--key '{"StudentID":{"N":"1"}}'

aws dynamodb update-item \
--table-name Students \
--key '{"StudentID":{"N":"1"}}' \
--update-expression "SET Name='Raj'"

# Delete Item
aws dynamodb delete-item 
--table-name Students 
--key '{"StudentID":{"N":"1"}}'
